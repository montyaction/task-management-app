Task Board API

Welcome to the Backend Service

This backend powers the Task Management Application. It provides authentication, task operations, board management, and health monitoring for production deployments.

Core Features

  • User registration and login with JWT authentication
  • Task CRUD and task reordering support
  • Board CRUD endpoints for organizing tasks
  • Rate limiting, secure headers, and CORS controls
  • Database-aware health endpoint for uptime monitoring

Primary API Routes

  • GET /api/health - service and database health
  • POST /api/auth/register - create account
  • POST /api/auth/login - authenticate user
  • /api/tasks - task operations
  • /api/boards - board operations

If you are seeing this page, the backend root route is configured successfully.
